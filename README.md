# Velora Insights Dashboard

Velora Insights Dashboard is a responsive web-based retail analytics project.  
It visualizes sales data through KPI cards, interactive charts, category filters, business insights, and a sales data table.

The project also includes a demo login page to simulate access control before entering the dashboard.

## Preview

### Login Page
The login page is designed as the entry point of the Velora Insights Dashboard. It includes a clean split-screen layout with a login form on the left side and a professional business image on the right side. The email field is pre-filled with demo credentials, allowing users to quickly test the project.

The page simulates a basic access-control flow before entering the dashboard. After entering the correct demo password, the user is redirected to the analytics dashboard.

![Login Page](https://github.com/ahmed-ghroubi/velora-insights-dashboard/blob/main/log-in)

### Dashboard Page
The dashboard page presents retail sales data in a modern and structured analytics interface. It includes a left sidebar navigation, a top search area, KPI cards, category filtering, interactive charts, quick statistics, business insights, and a sales data table.

The main purpose of the dashboard is to help users quickly understand sales performance, order volume, average order value, and the strongest product category. The charts visualize monthly sales trends and sales distribution by category, making the data easier to interpret.

The dashboard uses a clean blue and white design to create a professional business analytics look.

![Dashboard Page](https://github.com/ahmed-ghroubi/velora-insights-dashboard/blob/main/dashboard)
